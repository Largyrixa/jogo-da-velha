# jogo-da-velha
jogo da velha com bot baseado em minimax. 

para iniciar o jogo, por favor utilize o 'iniciar.bat' para que 'jogo.py' seja iniciado no diretório correto.

vá para [Versão em Português](https://github.com/Largyrixa/jogo-da-velha/tree/Português) para achar os arquivos.

# tic-tac-toe
tic-tac-toe with a minimax-based bot.

to start the game, please use the 'start.bat' so 'game.py' can be initialized in the right directory.

go to [English Branch](https://github.com/Largyrixa/jogo-da-velha/tree/English) branch to find the files.
